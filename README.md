# Mobilidade Urbana SP
### Guia Interativo de Transporte Coletivo

**Global Solution 2026.2 | CitizenTech | FIAP**

## 1. Sobre o Projeto

O **Mobilidade Urbana SP** é uma aplicação web desenvolvida para facilitar a consulta e a comparação de trajetos do metrô de São Paulo.

O projeto aborda dificuldades relacionadas à sobrecarga do transporte coletivo, ao planejamento das viagens e à identificação de rotas acessíveis.

A solução reúne informações de diferentes linhas em uma única página, permitindo que os usuários pesquisem, consultem detalhes e comparem trajetos.

## 2. Público-Alvo e Objetivo

A aplicação é destinada a trabalhadores, estudantes e cidadãos que utilizam o transporte público diariamente.

Seu objetivo é facilitar o acesso às informações sobre trajetos e ajudar os passageiros a planejar seus deslocamentos com mais facilidade.

## 3. Funcionalidades

- **Consulta de trajetos:** visualização de cinco linhas cadastradas, com origem, destino e tempo estimado.
- **Pesquisa:** busca por nome da linha, origem ou destino.
- **Filtro de acessibilidade:** seleção de trajetos conforme as informações de acessibilidade.
- **Detalhes:** consulta de estações, horários e outras informações do trajeto.
- **Comparador:** comparação entre duas linhas, considerando tempo estimado e acessibilidade.
- **Mapa oficial:** acesso direto ao mapa da rede do Metrô de São Paulo.
- **Layout responsivo:** adaptação para computadores, tablets e celulares.

## 6. Como Executar o Projeto

Acesse o repositório: https://github.com/haninatwi0/vaisp-mobilidade-urbana

Clique em Code > Download ZIP.

Extraia o arquivo baixado.

Abra a pasta do projeto.

Abra o arquivo index.html em um navegador, como Google Chrome ou Microsoft Edge.

Outra opção: abra a pasta do projeto no Visual Studio Code e execute o arquivo index.html utilizando a extensão Live Server.

## 7. Dados e Limitações

Os dados utilizados são ilustrativos e foram criados para demonstrar as funcionalidades da aplicação.

Os tempos de viagem, horários e informações de acessibilidade não representam dados oficiais ou atualizados do Metrô de São Paulo.

O projeto não utiliza APIs, banco de dados ou informações em tempo real.

Para consultar o mapa oficial, acesse:

https://www.metro.sp.gov.br/pt_BR/sua-viagem/mapa-da-rede/
